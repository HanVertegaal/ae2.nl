# ae2.nl

This repository contains the source for the **ae2.nl** website.

## Purpose

The site is intended to host help files and supporting web pages for **AE products**.

## Contents

- Product help and documentation pages
- Supporting static website assets
- Project configuration for the site repository

## Getting started

This repository is currently being initialized.

Suggested next steps:

1. Add the website source files.
2. Organize help content by product or topic.
3. Set up deployment for the ae2.nl domain.
