Results and Analysis

Draft for review: These DIRAC Field instructions are being reviewed. Screenshots will be added to illustrate the app pages.

Open a stored measurement

  1. Choose Projects from the menu, open the project and group, and tap the measurement.
  2. Check the title, data type and available views before interpreting a result.
  3. Select a Category, then select a View or Parameter within that category.

The current detail page opens the first successfully stored receiver recording in a measurement. It does not provide a receiver chooser. For a multi-receiver run, use the measurement metadata and an export containing all receiver recordings to check the remaining receivers, for example in desktop DIRAC.

A measurement with no successful recording cannot be inspected as a waveform. Keep failed or partially completed status distinct from a valid measurement whose numerical result happens to be small.

Inspect the signal

ViewUse
PressureInspect the waveform over time. Check capture length, unexpected disturbances, flat sections and overload.
ETCInspect the energy-time curve of an impulse response. This view is offered for impulse-response data.
SpectrumInspect how the recorded energy is distributed with frequency.
SpectrogramInspect how frequency content changes over the duration of the recording.

The offered views and parameter categories depend on Measurement Type. Ordinary recordings are Signals. Supported sequence processing can produce Impulse responses. If the classification is wrong, correct it through Edit Measurement Metadata; changing that classification alone does not calculate an impulse response from a raw recording.

Select an acoustic parameter

Parameter categories include Reverberation, Level, Speech and Ratio. Only parameters appropriate to the measurement are offered.

ParametersWhat they describe
EDT, T10, T20, T30Decay-based reverberation measures obtained from different parts of an impulse-response decay.
LeqEquivalent level calculated from stored pressure data. This is an analysis result, separate from Aether's live SLM controls.
INRImpulse-response-to-noise ratio, useful when checking whether the decay supports the desired analysis.
D50, C50, C80, TSDefinition, clarity and centre-time measures derived from the distribution of impulse-response energy.
MTI, STI, STIPASpeech-intelligibility results for the applicable data. A dedicated STIPA signal capture and an impulse-response calculation use different input data.

A result may be a single value or a set of frequency-band values. An unavailable band or result indicates that a usable value was not calculated; it is not equivalent to zero. Check the data, decay, noise and acquisition conditions before changing the measurement solely to obtain a number.

Speech calculations can also use speech/noise level metadata. Check any manual band-level entries, calibration and measurement conditions when comparing results. Source output gain and a measured sound level at the receiver are different quantities.

Set graph and table display options

For band-based parameter results, tap the settings/gear control to open Parameter display. Set the applicable options and tap Apply; Close dismisses the dialog without applying the proposed changes.

  • Band resolution: Full octave or Third-octave.
  • Representation: Graph or Table.
  • Graph style: Line or Bar, with optional grid and trace width.
  • X-axis range: the first and last displayed frequency bands.
  • Y-axis minimum/maximum: automatic limits, or explicit numerical values. A manual minimum must be below the maximum.

Display settings affect presentation and, where applicable, the requested band resolution. They do not correct clipped samples or turn an interrupted capture into a complete recording.

Listen to the stored recording

Tap the playback triangle on the detail page to audition the stored recording through the phone or tablet's audio output. Tap Stop to end auditioning. This is not a command to Echo, Atlas or HBK 2755. An unavailable-playback message concerns auditioning that stored data; the waveform and export may still be usable.

Check quality before reporting

Review the input waveform and, for an impulse response, the energy decay as well as the final parameter. Check receiver identity, source configuration, calibration, duration and site conditions. Export the measurement for further work when another receiver or more detailed analysis is needed.
