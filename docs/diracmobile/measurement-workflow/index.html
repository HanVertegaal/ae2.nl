Choose the right workflow

TaskStart here
Read or integrate a sound levelAether → SLM.
Record an existing soundAether → Recording or HBK 2255.
Play a source without capturing dataEcho/Atlas Play, or HBK 2755 White/Pink/User.
Acquire with a controlled sourceThe measurement/Record action on the source control page, with suitable receivers available.

The source's Play action and its measurement action are different. Play controls the sound source alone. A source-triggered measurement also prepares receivers, acquires their data and retrieves the results.

Prepare the measurement

  1. Choose an Echo, Atlas or HBK 2755 as the source, and Aether and/or HBK 2255 as receivers.
  2. Prepare the hardware, positions and microphone calibration. Use the equipment guides for physical connections and operating limits.
  3. Make the intended equipment reachable from DIRAC Field and authenticate it. Confirm the device identities before acquisition.
  4. Choose the project and group, check receiver-distance defaults, and note the site conditions.
  5. Configure an appropriate source signal. For a source-triggered run, stop ordinary playback first if the measurement action requires the source to be idle.

Several receivers can contribute to one run. The app discovers the available recorder set; the source control page is not a receiver-selection checklist. Check which recorders are present and inspect the result for each intended receiver.

Match signal and analysis

Use a supported measurement sequence when you require a processed impulse response. The app can process supported Echo/Atlas measurement sequences as part of capture. Ordinary noise playback, arbitrary user audio and an external input should not be assumed to produce an impulse response.

A dedicated STIPA acquisition is a signal-based speech-intelligibility workflow. Use the appropriate STIPA source configuration and review the corresponding STIPA result. A waveform's presence alone does not establish that its recording is suitable for that analysis.

The signal and its supported timing determine the source-driven run. Recording duration selected on a receiver's recording-only page is a separate setting. Review the actual saved duration instead of assuming it equals the rounded sequence-length label.

Run the acquisition

  1. Open the source control page and verify the signal and level or gain. Check the Save to destination.
  2. Use the source's measurement/Record control. It becomes available when the app has suitable receivers and, for Echo/Atlas, a supported measurement signal.
  3. Allow preparation, any signal buildup, capture, retrieval and processing to complete. Keep the app connected and the equipment stationary.
  4. If you stop or cancel, read the resulting state. Stop acquisition and Cancel are distinct actions where both are shown; an abandoned run must not be treated as complete.

HBK 2255 participates in a complete source-triggered run only after its BZ-7351 status has been verified as active. This prerequisite does not prevent ordinary recording-only captures from its own control page. See HBK 2255 prerequisites.

Verify every receiver result

Open the destination group. A completed multi-receiver measurement should have usable data for every intended receiver. A partially completed run means some receiver data succeeded and some did not; preserve the successful data and repeat the missing measurements where necessary. The current detail page opens the first successful receiver recording; export the complete measurement to inspect the other receivers.

Check waveform duration, clipping, background disturbance and the appropriate measurement type. Examine an impulse response and its decay before relying on reverberation or speech results. A missing result or band is not a zero value.

Finish and preserve the data

Stop source playback explicitly and check the device state, especially after a canceled run or lost connection. Review the results, add useful metadata, then export the required data. Confirm the exported file was saved before removing equipment or deleting local copies.
