Identify the installed versions

Open menu → About for the installed DIRAC Field application version. Open a connected device's Settings → ID for its Software version and serial number. App and device versions are separate and can change independently.

The controls and signal choices described here reflect the app functionality used to prepare this draft. Device-reported capabilities, installed device software and connection readiness can affect the controls offered on a particular installation.

Functionality covered by this guide

  • Discovery, manual address entry, device authentication and context-sensitive navigation.
  • Aether SLM and recording, Echo/Atlas and HBK 2755 source control, and HBK 2255 recording.
  • Projects, groups, capture destinations, measurement metadata and multi-receiver capture.
  • Signal views, supported acoustic parameters, graph/table display options and stored-audio auditioning.
  • DIRAC packages and WAV/CSV/TXT data export.
  • App settings, supported device settings, updates and Aether recovery actions.

Compatibility and current boundaries

Aether's SLM mode is not offered for the other devices. HBK 2255's BZ-7351 prerequisite applies to complete source-triggered measurements, while recording-only capture remains a separate workflow.

Each receiver result appears as a separate measurement entry in its destination group. Each receiver entry has its own measurement number. Open the entry for the receiver you want to inspect; its metadata, export, move and delete actions apply to that entry. Clear captures from earlier development builds before using the updated build; old captures are not converted.

Not every played signal is a supported impulse-response measurement stimulus. Use the configured signal, stored measurement type and offered analysis parameters together when choosing how to inspect a result.

Release history

A version-by-version published change history has not yet been added to this draft. No release date or compatibility guarantee should be inferred from the manual's copyright year. When seeking support, report the versions actually shown by the installed application and equipment.
