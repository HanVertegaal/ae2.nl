DIRAC Field/Quick Start

Quick Start

Draft for review: These DIRAC Field instructions are being reviewed. Screenshots will be added to illustrate the app pages.

On this page
  • Prepare the equipment
  • Choose where to save
  • Make a first recording
  • Inspect and save a copy
  • Finish the session

This first exercise makes a recording without controlling a sound source. Use an Aether or HBK 2255 as the receiver. For a run that controls a source as well, continue with Acoustic Measurement Workflow.

Prepare the equipment

  1. Prepare and power the receiver according to its hardware guide. Aether is normally used on its internal battery, with its microphone directly attached to the BNC input.
  2. Connect the phone or tablet and receiver to the same local network, or join the receiver's hotspot using the operating system's Wi-Fi settings.
  3. Open DIRAC Field and wait for the receiver to appear on Devices. Allow local-network access if the operating system asks.
  4. Tap the device card. Complete authentication if requested and wait until the control page is ready. See Connecting Devices if the device is missing or a password is rejected.

Choose where to save

On the recording control page, check the Save to field. It shows the project and group for the next measurement. Use its change button to choose another destination or create a project or group. You can also prepare these under menu → Projects.

For a first exercise, create a clearly named group such as First recordings. The destination applies to new captures; merely changing it does not move existing measurements.

Make a first recording

  1. If using Aether, select Recording in Mode. HBK 2255 opens its recording controls directly.
  2. Check that the input-level indication responds to sound. For calibrated results, complete the appropriate microphone calibration first.
  3. Choose Measurement duration and tap the Record control.
  4. Keep the equipment in place while the app prepares the receiver, records and retrieves the data. Aether may need microphone warm-up and its configured attention delay before recording.
  5. Wait until retrieval has finished. Read any error or partial-completion message before proceeding.

The capture workflow can include multiple available receivers. A measurement can therefore contain more than one receiver recording. Check the saved measurement's status and receiver metadata, and export the complete measurement when inspecting all receiver data. The open control page does not identify the only receiver involved.

Inspect and save a copy

  1. Open menu → Projects, then the destination project and group.
  2. Tap a successful measurement entry. Start with Category: Views and View: Pressure to inspect the waveform.
  3. Check the duration and signal quality. A flat, overloaded or interrupted recording should be investigated before relying on calculated results.
  4. Use Export to save a DIRAC package or data copy. Complete the system file-save dialog and wait for the export-complete message.

A plain recording is stored as a Signal. It is not automatically an impulse response. The Results and Analysis chapter explains how the data type controls the available analysis.

Finish the session

Stop any running acquisition and source playback explicitly. Confirm that the required receiver data can be opened and that important results have been exported before disconnecting equipment. Use the device's supported power-off action when finished.
