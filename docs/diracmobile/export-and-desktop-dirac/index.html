Export and Desktop DIRAC

Draft for review: These DIRAC Field instructions and illustrations are being reviewed.

On this page
  • Choose what to export
  • Export for desktop DIRAC
  • Export audio or calculated results
  • Save and verify the file

Choose what to export

Export is available from project and group actions and from a measurement's detail page. In a group, use Select to export a chosen set of measurements. Select the appropriate scope before choosing the file format.

A measurement can include several receiver recordings. Exporting a measurement package preserves the measurement context and available receiver data rather than only the waveform initially opened by the detail page.

Export for desktop DIRAC

  1. Tap Export for the required project, group, measurement or selection.
  2. Choose Export for Dirac (.dmpx).
  3. Wait while the app prepares the package.
  4. Complete the operating system's save dialog. Choose a location and filename you can find later.
  5. Wait for Export complete, then transfer the saved package to the computer using your usual file-transfer method.
  6. Open/import it using the compatible desktop DIRAC version's Field package workflow and verify the expected project, measurements and receiver data.

The package carries hierarchy, measurement metadata and available recordings. Use this format when you want to continue work in desktop DIRAC. A WAV alone does not carry all the same project and stimulus context.

If desktop DIRAC does not recognise a package, check the desktop version and its import support. Do not repair a package by renaming its extension. The detailed desktop commands belong in the DIRAC desktop guide.

Export audio or calculated results

  1. Choose Export data (WAV / CSV / TXT).
  2. Select WAV only, Calculated results only, or WAV plus calculated results.
  3. If results are included, choose CSV or TXT.
  4. Wait for preparation, complete the system save dialog and check the completion message.

A single eligible output can be saved directly. A set of files is packaged in a ZIP archive; extract it before opening the contained files in other applications.

WAV preserves audio data for suitable analysis tools. CSV and TXT provide calculated values for review or further processing. They do not replace the recording when reanalysis is needed. A missing or unavailable calculated value should not be interpreted as a measured zero.

Save and verify the file

Export preparation and saving are separate steps. Canceling the chooser or save dialog does not produce a completed saved export. If an export fails, retain the measurements in the app, resolve storage or permission problems, and retry.

Open the saved file or archive and check that its scope and contents are what you intended, particularly when exporting several receiver entries together. The system picker may save to local storage or a location offered by another application; check that any later transfer or synchronisation has completed.

Export copies data; it does not delete the measurements from DIRAC Field. Keep the app copy until the required backup or desktop import has been verified.
