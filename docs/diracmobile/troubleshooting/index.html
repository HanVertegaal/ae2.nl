Troubleshooting

Draft for review: These DIRAC Field instructions are being reviewed. Screenshots will be added to illustrate the app pages.

On this page
  • A device does not appear
  • A password is rejected
  • A control is absent or disabled
  • Aether's level is missing, stale or unexpected
  • Recording or retrieval fails
  • A measurement or parameter cannot be opened
  • Export or desktop import fails
  • Information for support

A device does not appear

  1. Check that the equipment is powered and ready, and that the phone/tablet is on the intended network.
  2. Check operating-system local-network permissions. A hotspot without internet can still be the correct measurement network.
  3. Pull down on Devices to refresh. If its current IP address is known, try manual Add Device.
  4. Check App settings → Forgotten Devices and Unblock the device if necessary.
  5. Check for access-point client isolation or a guest network that prevents devices communicating.

Use a device's physical recovery procedure only when ordinary access cannot be restored. Aether recovery-mode cards open different actions from normal device cards.

A password is rejected

Check whether the prompt requests the device password or an access-point password. For AE normal hotspots, use the active device password; the password of a separate site Wi-Fi network is unrelated.

If an old credential is stored, clear it for that device in App settings and enter the current password when reconnecting. This does not reset the device password. Aether factory-password restoration is available through its recovery workflow and preserves data; factory reset is a separate destructive action.

A control is absent or disabled

First check the device type. SLM belongs to Aether; source playback belongs to Echo, Atlas and HBK 2755; HBK 2255 is a receiver. A source's measurement action also needs eligible receivers. A network, update or calibration editor may be unavailable for a particular device.

Wait for connection or initialization to finish. Stop the current operation before changing mode or parameter, and stop ordinary Echo/Atlas playback before starting a source-triggered measurement. Check the BZ-7351 status when HBK 2255 is missing from source-measurement eligibility.

Aether's level is missing, stale or unexpected

Check the microphone attachment, calibration and selected parameter. A cumulative Lmin/Lmax measurement needs Start, and a timed Leq needs a valid interval. A final retained value is different from a still-running live value. An interrupted or stale indication should not be copied as a fresh completed measurement.

Repeat calibration when appropriate. Do not compensate for a damaged or overloaded waveform by merely changing a display scale or source gain after acquisition.

Recording or retrieval fails

Keep the receiver powered and connected during retrieval as well as recording. Check available storage, battery state, receiver readiness and the destination. Read the operation's error rather than assuming that returning to the control page means success.

A run can be partially completed when some receivers succeed and others fail. Preserve the successful data, keep any instrument recording available during investigation, and repeat the missing acquisition as needed. Do not erase equipment storage or factory-reset the receiver as the first response to a failed transfer.

During a source-triggered run, confirm that the selected stimulus is supported. Ordinary user audio, noise or external input is not automatically a processed impulse response. Stop the source explicitly after an interrupted workflow and check its actual state.

A measurement or parameter cannot be opened

Confirm that the measurement has a successful local recording. The detail page opens the first successful receiver recording; use a full export to examine other receivers. If an expected parameter is absent, check Signal versus Impulse response classification and whether that analysis is supported for the data.

Missing bands can reflect insufficient usable data, decay or signal-to-noise conditions. Check the waveform and acquisition conditions; a blank result is not zero. Correcting metadata does not repair clipped or missing samples.

Export or desktop import fails

Retain the app data, check local storage space and file-save permissions, and repeat the export for the intended scope. Complete the system save dialog and wait for Export complete. Verify that a transferred file has finished copying or synchronising.

Use Export for Dirac (.dmpx) for the desktop package workflow. For a data ZIP, extract its contents before opening individual files. Check desktop DIRAC package compatibility if the file is not recognised.

Information for support

Note the app version from About, device type/name/serial, device Software version, network arrangement, selected signal or SLM parameter, operation stage and exact error text. For a data problem, retain the original measurement and an export. A screenshot of the relevant app state is useful; keep actual passwords concealed.
