Using HBK 2755

Draft for review: These DIRAC Field instructions are being reviewed. Screenshots will be added to illustrate the app pages.

On this page
  • Select and play a signal
  • Adjust gain
  • Choose or upload User audio
  • Acquire with receivers
  • Settings

HBK 2755 is a playback source in DIRAC Field. Its control page uses White, Pink and User buttons instead of the Echo/Atlas signal configuration form. It does not provide a microphone recording or SLM mode.

Select and play a signal

  1. Open the HBK 2755 card on Devices and wait until the source is connected and authenticated.
  2. Tap White, Pink or User to play that signal. User uses the file currently assigned to the source's User selection.
  3. Check the highlighted signal and output state. Tap the active signal button again to stop it; selecting another signal changes the requested playback selection.

The controls follow the device's returned state. If a command fails or the connection is lost, confirm the actual source state before assuming that sound has stopped.

Adjust gain

The large gain readout and knob set output gain in dB. Drag the knob to the required setting and release it to finish the adjustment. The step size follows the source configuration. Allow the returned state to confirm the value.

Gain is an output adjustment, not a calibrated sound level at a receiver. Check the sound level and operating limits for the actual source and measurement arrangement. Leave gain fixed while a measurement is being acquired; the control is unavailable during an app-managed capture.

Choose or upload User audio

  1. Press and hold User to open User Signals. A short tap instead operates playback.
  2. Select a stored file and tap Set as User to assign it to the User button.
  3. To add audio, tap Upload, choose the supported source file and wait for transfer to complete. Then select and assign the intended uploaded file.
  4. Return to the control page and use a short User tap to play the assigned signal.

Use Delete to remove a selected user file from the source after confirmation. Retain an original copy if it will be needed again. Source file selection and project measurement selection are separate operations.

Acquire with receivers

When suitable receivers are available, the control page provides the Save to field and measurement action. Check the project/group, choose the signal and gain, then use the measurement action to run source playback and receiver acquisition together.

Allow signal buildup, capture and retrieval to finish. Check each receiver result in the destination group. Verify playback afterward and stop the source explicitly when finished. HBK 2755 noise or user playback must not be assumed to produce the processed impulse response offered for supported Echo/Atlas sequences.

If no suitable receiver is available, ordinary source playback remains a different task from measurement capture. See Acoustic Measurement Workflow and the HBK 2255 prerequisite.

Settings

menu → Settings opens the HBK 2755 device settings. Read its identity, reported software and battery information, and use the supported Network controls. Supported software-update actions are described in the common Device settings chapter. The unified AE device-password arrangement and Aether's LED and recovery procedures do not apply to HBK 2755.

For physical connections, source power and the HBK's own operating controls, use the documentation supplied with the equipment.
