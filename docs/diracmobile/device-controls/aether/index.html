Using Aether

Draft for review: These DIRAC Field instructions are being reviewed. Screenshots will be added to illustrate the app pages.

Aether provides both sound level measurement and recording in DIRAC Field. Its Mode selector chooses which controls the page displays. Stop the current operation before changing mode or the SLM parameter.

Read the control page

Control or indicationPurpose
Device name and connection stateConfirm the selected Aether and wait for connection to finish.
Battery indicationCheck the reported charge/charging state before a long session.
IdentifyBriefly illuminate the connected Aether's identification pattern.
ModeSelect SLM or Recording.
Level displayRead the selected SLM parameter. In SLM mode, tap it to configure the next measurement while stopped.
Measurement timeIntegration time in seconds for Leq; shown only when applicable.
Save to / Measurement durationDestination and recording length in Recording mode.
Transport controlStart/Stop for SLM; Record for signal capture.

Identify requires a working connection. It is a useful final identity check after connecting, not a way to establish the connection.

Measure a sound level

  1. Select SLM in Mode.
  2. While stopped, tap the level display to open the SLM configuration page.
  3. Choose Measurement type, Frequency weighting and, when applicable, Time weighting. Tap Apply to return to the control page. Cancel leaves the selection unchanged.
  4. For Leq, enter Measurement time (seconds) on the control page.
  5. Tap Start. Follow the measurement state as well as the numerical level.
  6. Use Stop for an ongoing measurement. A timed Leq ends at its configured interval; its final value remains displayed.

Applying a parameter prepares the next acquisition; it does not start it. Mode and parameter controls are unavailable while an operation is running.

Measurement typeMeaning and choices
LLive sound pressure level. Select A, B, C or Z frequency weighting and Fast (F), Slow (S), Impulse (I) or Peak detection. Runs until stopped.
LeqEnergy-average level over the specified measurement interval. Frequency weighting applies; a separate Fast/Slow detector does not.
LminLowest time-weighted level since Start. Select F or S. Continues until stopped.
LmaxHighest time-weighted level since Start. Select F or S. Continues until stopped.

Use the full parameter symbol when recording a reading; for example, LAeq and LAFmax describe different measurements. A final timed result is different from a live value that is still updating. If the connection is lost or the app reports an interruption, do not treat the last displayed number as a newly completed measurement.

The SLM controls display sound level results. They do not make a project waveform recording. To retain a waveform for later analysis and export, select Recording.

Record a signal

  1. Select Recording. Check the input indication and microphone calibration.
  2. Check Save to and choose Measurement duration.
  3. Tap Record and allow preparation to finish. Microphone warm-up and an attention delay may precede actual capture.
  4. Wait through acquisition and retrieval. Use the offered Stop or Cancel action only when you intend to interrupt the run, and check its resulting status.
  5. Open the destination group and inspect the successful receiver recording or recordings.

Recording-only capture can involve other available receivers as well as the Aether whose page is open. A source-triggered run starts instead from the source's page; see Acoustic Measurement Workflow.

Calibrate the microphone

  1. Stop SLM and recording. Fit and operate the acoustic calibrator according to the microphone and calibrator instructions.
  2. On the Aether control page, choose menu → Settings → Measurement → Calibrate.
  3. In Calibrate Aether, enter the actual calibrator level in dB and tap Start.
  4. Keep the assembly steady while the app reports warm-up, tone search and measurement. Use Cancel if you need to abandon the attempt.
  5. Wait for a successful result. On failure, check the connection, tone and entered level before retrying.
  6. Remove the calibrator before measuring and check the resulting sound level indication.

The app initiates calibration and reports its progress; the Aether retains the resulting calibration. Physical microphone compatibility, direct mounting and calibrator preparation are covered in Aether: Microphone and Calibration. Recheck calibration after replacing the microphone.

Aether settings

The common Device settings sections cover identity, network, password, power and software. Aether additionally provides:

  • Measurement: the default source–receiver distance and the calibration action.
  • LEDs: ordinary status brightness and pre-recording attention time. Save changes explicitly.
  • Service: factory reset with a physical confirmation sequence and final erase action.

Attention time is a delay before recording; it is not part of the waveform duration. Setting ordinary LED brightness to zero does not suppress the full-brightness attention indication. See Aether: Power and Status Indicators.

Recovery actions in the app

If normal access is unavailable, follow the physical procedure in Aether: Temporary recovery network. Join that network in the operating system, return to Devices, and tap the recovery-mode Aether card.

Restore factory password asks for the original factory password supplied with the equipment. On success it becomes the active password for remote access and the normal hotspot. This restoration preserves recordings and settings.

Factory reset is a different operation: it deletes recordings, saved networks, calibration and user settings and restores the factory password. Follow the app's physical confirmation instructions and read the final Erase and reset confirmation. Export required data before starting. Afterward, reconnect and recalibrate.
