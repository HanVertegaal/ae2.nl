Network

Network modes

Echo supports three network operating modes.

Mode Description
Off Wireless networking disabled
Station Connect to an existing Wi‑Fi network
Hotspot Create local wireless hotspot

Connecting to a network

  1. Press M
  2. Select Network
  3. Select Mode
  4. Choose Station
  5. Select Connect
  6. Choose an access point

Hotspot mode

In Hotspot mode, Echo creates its own wireless network.

The hotspot password can be configured from:

Menu → Network → Hotspot pwd

Remote access password

Access through the REST API can be protected using a password.

Configure the password from:

Menu → Network → Remote pwd
