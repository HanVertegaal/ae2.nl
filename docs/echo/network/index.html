Network modes

Echo supports three network operating modes.

Mode Description
Off Wireless networking disabled
Station Connect to an existing Wi‑Fi network
Hotspot Create local wireless hotspot

Connecting to an existing Wi-Fi network

Use the front panel to connect Echo to an access point:

  1. From the Home screen, press M and select Network.
  2. Choose Mode, then select Station.
  3. Select Connect and choose the network from the list.
  4. If prompted, enter the network password. Use L and R to choose characters and M to accept each character. Select the checkmark and press M when finished.
  5. Choose whether Echo should connect automatically to this network.

If the connection fails, Echo offers the option to enter the password again.

Creating a hotspot

In Hotspot mode, Echo creates its own Wi-Fi network for a direct connection.

  1. From the Home screen, press M and select Network.
  2. Choose Mode, then select Hotspot.
  3. On your phone or tablet, connect to Echo's Wi-Fi network using the device password.

The device password can be changed on the front panel under Menu → Network → Device pwd. This password is used for the hotspot and for remote access to the device. For help entering a password, see Entering text.

Remote control with DiracMobile

Use the DiracMobile app, available for Android and iOS, to control Echo remotely. Connect your mobile device to the same Wi-Fi network as Echo, or connect it directly to Echo's hotspot.

The DiracMobile help will provide details on connecting and using the app; its detailed documentation is being prepared.
