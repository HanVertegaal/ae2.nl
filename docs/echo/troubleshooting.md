# Troubleshooting

## No playback

- Verify output selection
- Verify signal configuration
- Verify playback level
- Verify playback has been started using **R**

---

## Cannot connect to network

- Verify network mode
- Verify Wi‑Fi password
- Restart networking
- Restart the device

---

## Playback stops unexpectedly

- Verify playback timer settings
- Verify auto-off settings
- Check battery charge level

---

## No signal on BNC output

- Verify output mode
- Verify playback is active
- Verify external equipment connections
