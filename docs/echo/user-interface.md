# User Interface

## Home screen

The Home screen is the primary operating screen.

| Button | Action |
|---|---|
| L | Open signal setup |
| M | Open system menu |
| R | Start or stop playback |

The currently selected signal, level and playback status are displayed on the OLED display.

---

## Navigation philosophy

Echo uses a shallow menu structure designed for quick field operation.

Typical workflow:

```text
Choose signal
→ Configure signal
→ Return home
→ Start playback
```

Most setup operations automatically return to the Home screen.

---

## Signal setup workflow

1. Select signal source
2. Select playback mode (if applicable)
3. Select duration
4. Select level
5. Return to Home screen
