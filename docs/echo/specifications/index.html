Stimulus level

Acoustic levels are A-weighted. For available settings and calibration points by signal, see Signal Setup.

ParameterSpecification
Pink MLS, ESweep and STIPACalibrated settings: 60 and 70 dBA; custom range: 40–80 dBA.
SpeechCalibrated setting: 60 dBA; custom range: 40–70 dBA.
Calibration tolerance and reference distance60 ± 1 dBA reference and 70 ± 1 dBA raised level, calibrated at 1 m in an anechoic room.

Input and output

ParameterSpecification
ConnectorsBNC line input and output; USB-C power.
Output modesSpeaker, BNC or Speaker+BNC.
Input voltage15 mV RMS nominal, pink noise at 60 dBA.
Input impedance at 1 kHz10 kΩ.
Output voltage120 mV RMS nominal noise signal; 1.5 V peak.
Output impedance at 1 kHz200 Ω.
