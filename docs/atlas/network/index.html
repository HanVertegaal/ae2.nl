Network modes

Atlas supports three network operating modes.

Mode Description
Off Wireless networking disabled
Station Connect to an existing Wi‑Fi network
Hotspot Create local wireless hotspot

Connecting to an existing Wi-Fi network

Use the front panel to connect Atlas to an access point:

  1. From the Home screen, press M and select Network.
  2. Choose Mode, then select Station.
  3. Select Connect and choose the network from the list.
  4. If prompted, enter the network password. Use L and R to choose characters and M to accept each character. Select the checkmark and press M when finished.
  5. Choose whether Atlas should connect automatically to this network. This choice is stored for that network; choosing No still permits this manual connection.

If the connection fails, Atlas offers Retry to enter the password again, or Forget to remove the saved network. Network → Forget also removes a selected saved network. This does not change the device password used for remote access.

If a saved Station network is unavailable, the device can open its own hotspot as a fallback and retry networks marked for automatic connection. Select Hotspot explicitly when you want a direct connection to remain in hotspot mode. Use Network → Info to check the current address and connection.

Creating a hotspot

In Hotspot mode, Atlas creates its own Wi-Fi network for a direct connection.

When connecting multiple devices, use a mobile Wi-Fi router (MiFi) or a mobile phone as the hotspot. Connect Echo, Atlas and any Aethers in Station mode to that shared network, together with the controller. Use the device hotspot for a direct connection to one device.

  1. From the Home screen, press M and select Network.
  2. Choose Mode, then select Hotspot.
  3. On your phone or tablet, connect to Atlas's Wi-Fi network using the device password.

The device password can be changed on the front panel under Menu → Network → Device pwd. This 8–63 character password is used for the hotspot and for remote access to the device. It is separate from the password of an existing Wi-Fi access point. Changing it can disconnect a controller using the hotspot; reconnect using the new password. For help entering a password, see Entering text.

Remote control with DIRAC Field

Use DIRAC Field on your phone or tablet to configure signals, start and stop playback, and acquire measurements with compatible receivers. Connect your mobile device to the same Wi-Fi network as Atlas, or connect it directly to Atlas's hotspot.

The DIRAC Field connection guide explains discovery, authentication and reconnection. See Using Echo and Atlas for the app's signal and playback controls.

Stop playback and acquisition before changing networks, passwords or device software. For the app's maintenance controls, including software update and supported rollback, see Device Settings and Maintenance.
