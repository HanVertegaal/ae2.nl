Stimuli

ParameterSpecification
Signal typesMLS-BA, MLS-RA, PMLS-BA, PMLS-RA, ESWP-BA, ESWP-RA, LSWP-BA, EqMLS-BA, User and BNC input
Frequency rangeBuilding Acoustics (BA): 63 Hz to 4 kHz octave bands.
Room Acoustics (RA): 63 Hz to 8 kHz octave bands.
Playback modes and sequence periodsDepend on signal type; see Signal Setup.

Stimulus level

Atlas uses gain settings from −60 to 0 dB for its built-in signals, User and BNC input. See Signal Setup.

Input and output

ParameterSpecification
ConnectorsBNC line input and output; USB-C power input.
Tripod mounting1/4-inch UNC threaded hole on the bottom. Three rubber feet support surface placement. See the bottom view.
Output modesSpeaker, BNC or Speaker+BNC.
Input voltage15 mV RMS nominal, pink noise at 60 dBA.
Input impedance at 1 kHz10 kΩ.
Output voltage120 mV RMS nominal noise signal; 1.5 V peak.
Output impedance at 1 kHz200 Ω.
