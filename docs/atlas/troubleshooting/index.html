Troubleshooting

On this page

No playback

  • Check Menu → Output: use Speaker or Speaker+BNC for acoustic output.
  • Check the selected signal and its level or gain. For User, verify that an uploaded signal is selected; for BNC input, verify that the external source is supplying audio.
  • Press R from the home screen to start playback. During playback R adjusts gain; press M to stop.
  • If a power warning appears, record its message and Avl/Req values. Follow Power limits and warnings before restarting.

Cannot connect to network

  • Check Network → Mode and Network → Info. Off disables remote access; Station and Hotspot require the controller to join the corresponding network.
  • Use the access-point password when joining an existing Wi-Fi network. Use the device password for the device hotspot and DIRAC Field authentication.
  • For a failed Station connection, select Retry and re-enter its password. Check the saved network's Auto-reconnect choice if it does not reconnect automatically.
  • After a mode or password change, reconnect the phone or tablet and reopen the device in DIRAC Field. See Remote Control and the app connection checks.

Playback stops unexpectedly

  • Check Timer → Timer and Duration. The playback timer stops the signal independently of its sequence length.
  • Check Power → Auto-off for battery-powered operation and check the battery charge.
  • Inspect any power or clipping indication and reduce the source level or output gain as described in Power limits and warnings.
  • If USB power was disconnected or briefly interrupted, Atlas stops playback. Reconnect a suitable supply and check the gain before starting again.

No signal on BNC output

  • Select BNC or Speaker+BNC under Menu → Output.
  • Check playback, the selected source and its level, then check the external equipment and cable.
  • Confirm that the cable is connected to the BNC output, rather than the input.

Self-test reports Fail

Repeat the self-test preparation: stop playback and acquisition, select Speaker output, ensure adequate power and leave the loudspeaker grilles unobstructed. Let all three measurements finish.

If Fr: … Hz (…) is shown, record both values. A Fail with this line means the measured resonance is outside the stored tolerance; Fail without it means no usable result was obtained. If it persists, contact Acoustics Engineering with the device identity and a photograph of the display. The reference and tolerance are factory settings and cannot be changed by the user. Repeat the test in a quiet environment before requesting service.

Information for support

Include the serial number and software version from Service → About, the selected signal and gain, output mode, battery/USB power condition, exact message and the steps that reproduce it. For a remote-control problem, also include the DIRAC Field version and the current network mode and address.
