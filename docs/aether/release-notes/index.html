Installed version

DIRAC Field shows the software version reported by the connected Aether. Include this version and the device serial number when reporting a problem.

Updating Aether

Use DIRAC Field to check for and install an available update. Stop measurements and recordings first, maintain stable power, and let the device restart and reconnect before continuing.

For device behaviour during updates and the retained-image rollback option, see Troubleshooting and Recovery. The DIRAC Field guide covers the application controls.
