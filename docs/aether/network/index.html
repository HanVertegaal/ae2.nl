Aether / Remote Control

Remote Control

Aether is normally used wirelessly with DIRAC Field. Connect it to the same local network as the device running DIRAC Field, or connect that device directly to Aether's hotspot. The same Wi-Fi connection options apply when using Aether for recording with DIRAC on a desktop computer; the desktop application does not support Aether's SLM function.

For multiple devices, use a mobile Wi-Fi router (MiFi) or a mobile phone as the hotspot. Connect Aether, Echo and Atlas in Station mode to this shared network, together with the phone, tablet or computer running DIRAC Field. Their own hotspots are intended for a direct connection to one device.

Network modes

ModeUse
StationAether joins an existing Wi-Fi network. The controlling device must be able to reach it on that network.
HotspotAether creates a protected Wi-Fi network for direct local control.

Direct hotspot connection

When Aether is in Hotspot mode, join its Wi-Fi network using the device password, then select Aether in DIRAC Field. A direct device hotspot does not itself provide internet access. Your phone, tablet or computer may report that the network has no internet connection.

The normal hotspot uses the same device password as authenticated remote access. It is separate from the temporary recovery hotspot described under Troubleshooting and Recovery.

Existing Wi-Fi networks

Use DIRAC Field to select an access point, enter its network password and choose whether Aether should connect automatically. The access-point password belongs to that network and can differ from the Aether device password.

Saved networks can be retained even when out of range. Automatic connection applies to networks for which it is enabled. If a connection cannot be completed, Aether can try another saved automatic network and provide a fallback hotspot.

Changing network mode or joining another network can interrupt the control connection. Reconnect the controlling device to the appropriate network and select Aether again. For application steps, see the DIRAC Field guide.

Device password

The device password protects normal remote control and the normal Aether hotspot. Keep the factory password supplied with the device available for recovery. Changing the device password may require reconnecting both Wi-Fi and the app.

If the current password is lost, the factory password can be restored without deleting measurements. See Password recovery.

Connection checks

  • Check that Aether is powered and that the controlling device is on the intended network.
  • Use a local network that permits communication between connected devices. Guest-network or client-isolation settings can prevent discovery and control.
  • Move closer to the access point or Aether when the signal is weak.
  • If Aether is visible but authentication fails, check the device password rather than changing the access-point password.
