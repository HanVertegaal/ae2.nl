Aether is a portable microphone interface and recorder for acoustic measurements. It is normally used wirelessly with DIRAC Field, running from its internal battery, and can store recordings on its internal SD card. A 1/2-inch measurement microphone is normally supplied with Aether and connects directly to its BNC input.

DIRAC Field supports both live sound level measurement (SLM) and recording with Aether. The desktop version of DIRAC also supports Aether for recording; it does not support Aether's SLM function.

Main functions

  • IEPE power for a compatible measurement microphone.
  • Acoustic calibration using a 1 kHz calibrator.
  • Live sound level measurements and signal recording, controlled from DIRAC Field.
  • Battery operation, with USB-C for charging or external power when required.
  • LED indications for connection, calibration, recording and charging.

Connections and controls

The internal orientation sensor supports wake-up and the deliberate movement sequences used for recovery. The Wi-Fi interface connects Aether through an existing network or its own hotspot; see Remote Control.

Using this guide

Start with Quick Start. This guide explains Aether's connections, microphone requirements, power behaviour and recovery procedures.

The DIRAC Field guide covers application workflows such as selecting measurement parameters, managing projects, retrieving recordings and analysing results. Its Using Aether chapter describes the app's SLM, recording, calibration and settings controls.

For recording workflows in the desktop application, see the DIRAC guide.
